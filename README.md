# 💻 TechStore

Site moderno e responsivo desenvolvido para uma loja de eletrônicos, com design clean e foco em conversão. Apresenta produtos de forma organizada, com navegação simples e layout tecnológico. Conta com integração ao WhatsApp para facilitar o contato e impulsionar vendas, oferecendo experiência rápida e profissional.

🔗 **Ver online:** https://tech-store-jet-rho.vercel.app

## ✨ Destaques

- Layout **responsivo**, pensado primeiro para o celular
- Contato direto pelo **WhatsApp**, para converter visitante em cliente
- Animações suaves com **Motion** e ícones **Lucide**
- Página única, leve e com carregamento rápido via **Vite**

## 🛠️ Tecnologias

| Camada | Ferramenta |
|---|---|
| Interface | React + TypeScript |
| Estilo | Tailwind CSS |
| Animações | Motion |
| Build | Vite |
| Deploy | Vercel |

## ▶️ Como rodar localmente

```bash
git clone https://github.com/Bruno-Gadelha25/TechStore.git
cd "TechStore/techstore"
npm install
npm run dev
```

Acesse **http://localhost:3000**.
